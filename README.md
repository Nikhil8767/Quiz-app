This is a command-line based quiz application developed using Golang. The app presents users with a series of multiple-choice questions, reads user input from the terminal, and provides instant feedback on correct or incorrect answers. It features a simple and interactive interface, supports timed quizzes, and reads questions from a CSV or JSON file, making it easy to extend or customize the quiz content.

Key Features:

Terminal-based user interface

Multiple-choice questions with score tracking

CSV/JSON-based question bank

Timer support for each question (optional)

Real-time feedback on user answers

Lightweight and fast execution with Go

Technologies Used:

Go (Golang)

Standard libraries: fmt, os, bufio, encoding/csv, time
